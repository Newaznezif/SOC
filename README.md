### Newaz Nezif - Cybersecurity Analyst

[LinkedIn](https://www.linkedin.com/in/newaz-nezif-285439262/)

A curated collection of free TryHackMe rooms designed for practical Security Operations Center (SOC) training. This repository helps aspiring and current SOC analysts build hands-on skills in SIEM investigation, threat hunting, incident response, Windows and Linux log analysis, and digital forensics.

## Why this repository matters

This list is ideal for:

- SOC analysts and junior defenders
- Blue team and DFIR learners
- Cybersecurity students preparing for certifications
- Professionals building a practical SOC skillset

Core skills covered include:

- Alert triage and investigation
- Incident response and playbooks
- Threat hunting and detection engineering
- Windows and Linux log analysis
- Network traffic and packet analysis
- Memory forensics and malware detection
- SIEM tools such as Splunk, ELK, and Wazuh

## Learning focus areas

- Security operations fundamentals
- Defensive security and threat intelligence
- SIEM and log analysis
- Endpoint and network detection
- Incident response and triage
- Malware analysis and YARA
- Forensics and memory analysis

## Additional room sources imported from upstream

The repository at https://github.com/subhadeep404/TryHackMe-SOC-Rooms was reviewed and added as a companion reference file in this folder: [tryhackme-soc-rooms-source.md](tryhackme-soc-rooms-source.md).

Duplicate room checks were performed by normalized TryHackMe room slug. The overlap was limited to 16 known rooms already present in this list, and the remaining unique rooms were retained in the source reference file for broader SOC, DFIR, malware, and purple-team coverage.

The repository at https://github.com/AtikBagwan00/tryhackme-soc-free-labs was also reviewed. A duplicate slug check showed the full room set matches this repository exactly, so its contents were archived under [external-sources/atikbagwan00-tryhackme-soc-free-labs](external-sources/atikbagwan00-tryhackme-soc-free-labs) instead of adding duplicate entries to the main curated list.

## How to use this repository

1. Log in to TryHackMe.
2. Open the room links above.
3. Complete the labs in sequence based on your comfort level.
4. Practice the techniques in your own lab environment.
5. Build a consistent SOC workflow around detection, response, and documentation.

## Recommended progression

A practical order for learning might be:

- Defensive Security Intro
- Introduction to SIEM
- Intro to Logs
- Windows Log Analysis
- Linux Threat Detection 1
- Network Traffic Basics
- SOC Alert Triage
- IR Playbooks
- Threat Hunting Without Logs
- Memory Forensics and YARA
